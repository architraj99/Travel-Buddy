# Travel Buddy Planner

A simple travel planning website built by me
This project helps users organize trip ideas... save destinations.... add budgets
and keep travel plans in one place through a clean  interface.

## Features

* You can easily add travel destinat
* You can add more about it ( like the arrival date and the total budget )
* Total Budget section 
* A coool background image is added
* Simple and lightweight 


## Tech

* HTML5
* CSS3
* Java

## How to Run

1. Click on the link
2. after the website opens.
3. Add the Destination and Budget 
4. Also you can add things in checklist 

## Why I Built This

I wanted to create a practical website that helps travelers organize ideas and plans without needing complicated tools or accounts.
